# 车站无障碍通道复核器

暴雨倒灌后，车站里“看起来最近”的无障碍通道可能因积水封闭。本工具是一个
**仅在浏览器内运行**的复核器：审核员在网格中编辑阻断格、通行格与电梯格，点选
起点、终点和初始朝向，由求解器给出可逐步核对的最优路线，或在不可达时给出可
复核的失败证据。

- 纯前端：TypeScript + React 18 + Vite，**没有业务后端、不调用任何在线服务**；
  所有求解都在浏览器进程内完成。
- 网格最大 20×20。

## 计费与求解规则

- **格类型**
  - 通行格：步行进入按该格耗时计费，耗时为 1–99 秒的整数。
  - 阻断格：积水封闭，不可进入，也不能作为起点/终点。
  - 电梯格：带「组号」与「该组首次等待秒数」；同组电梯的等待秒数必须一致
    （否则“该组等待”没有唯一定义，校验会逐格报错）。
- **相邻正交移动（北/东/南/西）**：基础耗时 = 目标格耗时（步入电梯格为 0）；
  移动方向与当前朝向不同（含 180° 折返）时加收 **5 秒转弯费**，朝向更新为
  移动方向。
- **电梯乘用**：站在电梯格上可到达**同组任意另一部**电梯，固定 **8 秒**，
  **朝向不变**；该组第一次乘用时加收一次等待秒数，随后同组再乘用只收 8 秒。
- **求解状态** = `(位置, 朝向, 已付费电梯组集合)`，用 Dijkstra（二叉堆）在
  该状态图上求最优，已付费组用位掩码随状态传播。
- **优化目标（字典序）**：
  1. 总秒数最少；
  2. 转弯次数最少；
  3. 从起点起逐项比较的 `(行号, 列号)` 坐标序列取小者（行号优先，再比列号）。
- **结果展示**：每一步的基础耗时、转弯费、电梯费（含其中的首次等待）与累计
  秒数；网格上同步高亮路线与步序。
- **不可达**：封闭后若无路，旧路线立即消失，并显示**从起点不计成本可达的格数
  （含起点）**与逐格清单/圆点标记，作为可复核的失败证据。可达性泛洪同样允许
  同组电梯互达。

## 本地运行（Node 20+）

```bash
npm ci          # 或 npm install
npm run dev     # 开发服务器，默认 http://localhost:5173
```

生产构建与本地预览：

```bash
npm run build
npm run preview
```

## 测试

```bash
npm test                 # Vitest 单元测试（求解器 + 校验）
npx playwright install   # 首次运行端到端测试前安装浏览器
npm run e2e              # Playwright 交互测试（自动拉起 Vite）
npm run verify           # 一次性验收：构建 + Vitest + Playwright
```

测试覆盖（不是固定结果/占位逻辑，均由真实求解器计算）：

- 直行/转向计费、初始朝向、目标格耗时累计；
- 三级字典序优化目标（秒数 → 转弯数 → 坐标序列）；
- 电梯固定 8 秒、朝向不变、同组首次等待只收一次、不同组分别收取；
- 阻断包围导致不可达时的可达格数证据、电梯突围后的可达性泛洪；
- 非法尺寸、耗时、组号、等待、起终点/朝向缺失等错误的字段级定位；
- 界面交互：编辑后旧结果立即清空、错误定位高亮、电梯与不可达端到端流程。

## Docker Compose

无需在本机安装 Node，仓库自带多阶段 Dockerfile（构建阶段产生纯静态文件，
运行阶段只有 nginx）。

启动可用页面（宿主端口默认 8080）：

```bash
docker compose up --build
# 浏览器打开 http://localhost:8080
```

用 `WEB_PORT` 覆盖宿主端口：

```bash
WEB_PORT=9000 docker compose up --build
```

一次性验收服务 `verify`（构建 + Vitest + Playwright，跑完即退出）：

```bash
docker compose --profile verify run --rm --build verify
```

## 目录结构

```
src/
  core/
    types.ts        # 领域模型（格、朝向、场景）
    validation.ts   # 表单 -> 校验，字段级错误定位
    solver.ts       # 状态扩展 Dijkstra 与可达性泛洪
  components/       # 网格、格检查器、错误面板、结果面板
  App.tsx           # 编辑/点选/求解状态编排
tests/
  unit/             # Vitest：求解与校验
  e2e/              # Playwright：浏览器交互
docker-compose.yml  # web（WEB_PORT 可覆盖）+ 一次性 verify
Dockerfile          # build / web / verify 多目标
```
